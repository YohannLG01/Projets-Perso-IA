
# 📚 Projets IA en Python par Domaine

Ce dépôt regroupe une série de projets personnels en **Python**, chacun basé sur un **domaine clé de l'intelligence artificielle**. Chaque projet est associé à un dataset public (souvent issu de Kaggle) pour pratiquer les compétences de data science et de machine learning.

---

## 🧠 Domaines & Projets

### 1. 🛳️ Classification Supervisée – Titanic
- **Objectif** : Prédire la survie des passagers avec régression logistique.
- **Dataset** : [Titanic – Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic)

### 2. 🏠 Régression – House Prices
- **Objectif** : Estimer les prix de maisons via features engineering, random forest, XGBoost.
- **Dataset** : [House Prices – Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

### 3. 🌸 Classification Multi-classe – Iris
- **Objectif** : Classifier les fleurs Iris avec SVM et arbres de décision.
- **Dataset** : [Iris Dataset](https://scikit-learn.org/stable/auto_examples/datasets/plot_iris_dataset.html)

### 4. 🗺️ Clustering – Airbnb NYC
- **Objectif** : Regrouper les quartiers selon le prix et l’activité.
- **Dataset** : [NYC Airbnb Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

### 5. 👟 Vision par Ordinateur – MNIST & Fashion-MNIST
- **Objectif** : Reconnaissance d’images avec CNN simples.
- **Datasets** :
  - [MNIST digits](https://www.kaggle.com/competitions/digit-recognizer)
  - [Fashion-MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist)

### 6. 🧸 Vision par Ordinateur Avancé – CIFAR-10
- **Objectif** : Classification d’objets avec CNN profonds ou transfer learning.
- **Dataset** : [CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html)

### 7. 📝 NLP – IMDB & Disaster Tweets
- **Objectif** : Analyse de sentiments et classification de textes.
- **Datasets** :
  - [IMDB Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
  - [Disaster Tweets](https://www.kaggle.com/competitions/nlp-getting-started)

### 8. 🎮 Renforcement – CartPole
- **Objectif** : Maintenir l’équilibre d’un bâton avec un agent IA (Q-learning / DQN).
- **Dataset/env.** : [OpenAI Gym CartPole](https://www.gymlibrary.dev/environments/classic_control/cart_pole/)

### 9. 🧬 Classification Médicale – Diabète
- **Objectif** : Prédire la présence de diabète avec un classifieur binaire.
- **Dataset** : [Pima Indians Diabetes Database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)

### 10. 📈 Séries Temporelles – Ventes futures
- **Objectif** : Prédire les ventes avec modèles temporels (XGBoost/LSTM).
- **Dataset** : [Predict Future Sales](https://www.kaggle.com/competitions/competitive-data-science-predict-future-sales)
